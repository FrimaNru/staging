# Скрипт для добавления ссылок на Яндекс Маркет

## Описание
Скрипт `add-yandex-market-urls.js` позволяет массово добавить ссылки на Яндекс Маркет для товаров в базе данных.

## Использование

### Вариант 1: Использование JSON файла (рекомендуется)

1. Скопируйте пример файла:
   ```bash
   cp scripts/yandex-market-mapping.example.json scripts/yandex-market-mapping.json
   ```

2. Откройте `scripts/yandex-market-mapping.json` и заполните маппинг:
   ```json
   {
     "маппинг": {
       "ART-001": "https://market.yandex.ru/product/123456",
       "Кольцо золотое": "123456",
       "ART-002": "/product/789012?generalContext=..."
     }
   }
   ```

3. Запустите скрипт:
   ```bash
   # Windows PowerShell
   $env:ADMIN_TOKEN="ваш_токен_админа"
   node scripts/add-yandex-market-urls.js

   # Linux/Mac
   export ADMIN_TOKEN="ваш_токен_админа"
   node scripts/add-yandex-market-urls.js
   ```

### Вариант 2: Прямое редактирование скрипта

Отредактируйте переменную `PRODUCT_URLS_MAP` в файле `scripts/add-yandex-market-urls.js`:

```javascript
const PRODUCT_URLS_MAP = {
    'ART-001': 'https://market.yandex.ru/product/123456',
    'Кольцо золотое': '123456',
    'ART-002': '/product/789012?generalContext=...'
};
```

## Формат ссылок

Скрипт поддерживает несколько форматов ссылок:

1. **Полная ссылка**: `https://market.yandex.ru/product/123456` - используется как есть
2. **Относительный путь**: `/product/123456?generalContext=...` - добавляется к базовому URL магазина
3. **Только ID или путь**: `123456` или `product/123456` - формируется полная ссылка с параметрами

## Поиск товаров

Скрипт ищет товары по:
- Артикулу (точное совпадение)
- Названию (точное совпадение)
- Артикулу (без учета регистра)
- Названию (без учета регистра)

## Получение ссылок на товары из Яндекс Маркета

1. Откройте магазин в Яндекс Маркете: https://market.yandex.ru/business--mi-alegria/216411290
2. Найдите нужный товар
3. Скопируйте ссылку на товар из адресной строки браузера
4. Добавьте её в маппинг по артикулу или названию товара

## Примечания

- Скрипт автоматически пропускает товары, которые уже имеют такую же ссылку
- Между запросами есть задержка 500мс, чтобы не перегружать сервер
- Если товар не найден, он будет пропущен с предупреждением
