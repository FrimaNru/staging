ПОДРОБНАЯ ИНСТРУКЦИЯ: КАК СОХРАНИТЬ JSON И ОБНОВИТЬ ССЫЛКИ
═══════════════════════════════════════════════════════════════

ШАГ 1: СОХРАНЕНИЕ JSON ИЗ КОНСОЛИ БРАУЗЕРА
═══════════════════════════════════════════════════════════════

У вас в консоли браузера есть результат выполнения скрипта - массив из 137 товаров.

СПОСОБ 1 (Самый простой):
──────────────────────────
1. В консоли браузера найдите строку с выводом "📋 Полный JSON:"
2. Под ней должен быть массив JSON, начинающийся с [
3. Выделите весь массив (от [ до последнего ])
4. Скопируйте (Ctrl+C)
5. Откройте файл: scripts/yandex-market-products.json
6. Вставьте скопированный JSON (Ctrl+V)
7. Сохраните файл (Ctrl+S)

СПОСОБ 2 (Через консоль):
──────────────────────────
1. В консоли браузера найдите массив товаров (137) [{…}, {…}, ...]
2. Кликните на этот массив - он развернется
3. Кликните правой кнопкой мыши на развернутый массив
4. Выберите "Copy object" или "Сохранить объект как глобальную переменную"
5. Если появилась переменная (например temp1), выполните:
   copy(JSON.stringify(temp1, null, 2));
6. Откройте файл scripts/yandex-market-products.json
7. Вставьте скопированный JSON (Ctrl+V)
8. Сохраните файл (Ctrl+S)

СПОСОБ 3 (Выполнить скрипт еще раз):
──────────────────────────────────────
1. Вернитесь на страницу Яндекс Маркета
2. Откройте консоль (F12)
3. Выполните скрипт parse-yandex-simple.js еще раз
4. Сразу после выполнения выполните в консоли:
   
   // Сохраните результат в переменную
   const yandexProducts = (результат из консоли);
   
   // Скопируйте JSON
   copy(JSON.stringify(yandexProducts, null, 2));
   console.log('✅ JSON скопирован!');
   
5. Откройте файл scripts/yandex-market-products.json
6. Вставьте скопированный JSON (Ctrl+V)
7. Сохраните файл (Ctrl+S)


ШАГ 2: ПРОВЕРКА ФАЙЛА
═══════════════════════════════════════════════════════════════

Откройте файл scripts/yandex-market-products.json и убедитесь, что:
✓ Файл начинается с [
✓ Файл заканчивается на ]
✓ Внутри есть объекты с полями: "title", "url", "productId"
✓ JSON валидный (можно проверить на jsonlint.com)

Пример правильного формата:
[
  {
    "title": "vera",
    "url": "https://market.yandex.ru/card/vera/4723327312?...",
    "productId": "4723327312"
  }
]


ШАГ 3: ЗАПУСК СОПОСТАВЛЕНИЯ
═══════════════════════════════════════════════════════════════

1. Откройте терминал (PowerShell или Command Prompt)

2. Перейдите в папку проекта:
   cd C:\Users\la1zerr\Documents\GitHub\mialegria

3. Запустите скрипт сопоставления:
   node scripts/match-products-with-yandex.js

4. Скрипт выведет:
   - Сколько товаров загружено из БД
   - Сколько товаров загружено из Яндекс Маркета
   - Сколько товаров сопоставлено
   - Сколько товаров не найдено

5. После выполнения появятся файлы:
   - scripts/yandex-market-mapping.json (маппинг товаров)
   - scripts/yandex-market-unmatched.json (если есть несовпавшие товары)


ШАГ 4: ОБНОВЛЕНИЕ ССЫЛОК В БД
═══════════════════════════════════════════════════════════════

ВАРИАНТ A: Через админ-панель (РЕКОМЕНДУЕТСЯ)
───────────────────────────────────────────────
1. Откройте сайт в браузере
2. Войдите в админ-панель
3. Перейдите в раздел "Товары"
4. Нажмите кнопку "Массовое обновление Яндекс Маркет"
5. Откройте файл scripts/yandex-market-mapping.json
6. Скопируйте ВСЁ его содержимое (Ctrl+A, Ctrl+C)
7. Вставьте в текстовое поле модального окна (Ctrl+V)
8. Нажмите кнопку "Обновить"
9. Дождитесь завершения (появится сообщение с результатами)

ВАРИАНТ B: Через скрипт
─────────────────────────
1. В терминале установите токен админа:
   $env:ADMIN_TOKEN="ваш_токен_админа"
   
   (Токен можно найти в localStorage браузера:
    F12 → Application → Local Storage → tokenAdmin)

2. Запустите скрипт обновления:
   node scripts/add-yandex-market-urls.js

3. Скрипт обновит все товары и покажет статистику


ШАГ 5: ПРОВЕРКА РЕЗУЛЬТАТА
═══════════════════════════════════════════════════════════════

1. Откройте любую карточку товара на сайте
2. Если у товара есть ссылка на Яндекс Маркет, должна появиться кнопка:
   "Купить через Яндекс Маркет"
3. Кнопка должна быть:
   - Под кнопкой "КУПИТЬ"
   - С логотипом Яндекс Маркета слева
   - Бежевого цвета (как кнопка "КУПИТЬ" в состоянии hover)
4. При клике должна открываться страница товара в Яндекс Маркете в новой вкладке

РЕШЕНИЕ ПРОБЛЕМ

Проблема: Не могу скопировать JSON из консоли
Решение: Используйте Способ 1 - скопируйте текст JSON напрямую

Проблема: Файл не найден при запуске скрипта
Решение: Убедитесь, что файл scripts/yandex-market-products.json существует
         и находится в правильной папке

Проблема: JSON невалидный
Решение: Проверьте файл на jsonlint.com и исправьте ошибки

Проблема: Товары не сопоставляются
Решение: Проверьте файл scripts/yandex-market-unmatched.json
         и добавьте недостающие сопоставления вручную

Проблема: Ошибка при обновлении
Решение: Проверьте ADMIN_TOKEN и формат JSON в маппинге
