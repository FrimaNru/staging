# Подробная инструкция по добавлению ссылок Яндекс Маркет

## ШАГ 1: Сохранение JSON из консоли браузера

### Вариант A: Через консоль браузера (рекомендуется)

1. **Вернитесь в консоль браузера**, где вы выполнили скрипт `parse-yandex-simple.js`
2. Найдите в консоли массив товаров (он должен быть виден как `(137) [{…}, {…}, ...]`)
3. **Кликните правой кнопкой мыши** на этот массив в консоли
4. Выберите **"Copy object"** или **"Сохранить объект как глобальную переменную"**
5. Если такой опции нет, выполните в консоли:
   ```javascript
   // Найдите переменную с результатом (обычно она называется temp1 или подобное)
   // Или выполните скрипт еще раз и сохраните результат:
   const yandexProducts = (function() {
       // ... весь код из parse-yandex-simple.js ...
   })();
   
   // Затем скопируйте JSON:
   copy(JSON.stringify(yandexProducts, null, 2));
   console.log('✅ JSON скопирован в буфер обмена!');
   ```

6. **Откройте файл** `scripts/yandex-market-products.json` в редакторе
7. **Вставьте** скопированный JSON (Ctrl+V)
8. **Сохраните файл** (Ctrl+S)

### Вариант B: Ручное копирование

1. В консоли браузера найдите вывод `📋 Полный JSON:`
2. Скопируйте весь массив JSON (от `[` до `]`)
3. Вставьте в файл `scripts/yandex-market-products.json`
4. Сохраните файл

---

## ШАГ 2: Проверка файла

Убедитесь, что файл `scripts/yandex-market-products.json` содержит валидный JSON:
- Должен начинаться с `[`
- Должен заканчиваться на `]`
- Должен содержать объекты с полями `title`, `url`, `productId`

Пример правильного формата:
```json
[
  {
    "title": "vera",
    "url": "https://market.yandex.ru/card/vera/4723327312?...",
    "productId": "4723327312"
  },
  {
    "title": "mariana-zolotaya",
    "url": "https://market.yandex.ru/card/mariana-zolotaya/4729997110?...",
    "productId": "4729997110"
  }
]
```

## ШАГ 3: Запуск сопоставления товаров

1. **Откройте терминал** (PowerShell или Command Prompt)
2. **Перейдите в папку проекта**:
   ```bash
   cd C:\Users\la1zerr\Documents\GitHub\mialegria
   ```

3. **Запустите скрипт сопоставления**:
   ```bash
   node scripts/match-products-with-yandex.js
   ```

4. Скрипт:
   - Загрузит товары из вашей БД
   - Загрузит товары из файла `yandex-market-products.json`
   - Сопоставит их по названиям
   - Создаст файл `scripts/yandex-market-mapping.json` с маппингом
   - Покажет статистику: сколько товаров сопоставлено, сколько не найдено

---

## ШАГ 4: Проверка результатов сопоставления

После выполнения скрипта проверьте:

1. **Файл `scripts/yandex-market-mapping.json`** - содержит маппинг товаров и ссылок
2. **Файл `scripts/yandex-market-unmatched.json`** (если есть) - товары, которые не удалось сопоставить автоматически

Если некоторые товары не сопоставились, их нужно будет добавить вручную.

## ШАГ 5: Обновление ссылок в БД

### Вариант A: Через админ-панель (рекомендуется)

1. **Откройте админ-панель** → Товары
2. **Нажмите кнопку** "Массовое обновление Яндекс Маркет"
3. **Откройте файл** `scripts/yandex-market-mapping.json`
4. **Скопируйте весь его содержимое** (Ctrl+A, Ctrl+C)
5. **Вставьте в модальное окно** в админ-панели
6. **Нажмите "Обновить"**

### Вариант B: Через скрипт

1. **Установите ADMIN_TOKEN** (если еще не установлен):
   ```powershell
   $env:ADMIN_TOKEN="ваш_токен_админа"
   ```

2. **Запустите скрипт обновления**:
   ```bash
   node scripts/add-yandex-market-urls.js
   ```

## ШАГ 6: Проверка результата

1. Откройте любую карточку товара на сайте
2. Если у товара есть ссылка на Яндекс Маркет, должна появиться кнопка **"Купить через Яндекс Маркет"**
3. Кнопка должна быть под кнопкой "КУПИТЬ"

## Решение проблем

### Проблема: JSON не копируется из консоли
**Решение**: Выполните скрипт еще раз и сразу после выполнения выполните:
```javascript
copy(JSON.stringify(результат, null, 2));
```

### Проблема: Файл не найден при запуске скрипта
**Решение**: Убедитесь, что файл `scripts/yandex-market-products.json` существует и содержит валидный JSON

### Проблема: Товары не сопоставляются
**Решение**: 
- Проверьте файл `scripts/yandex-market-unmatched.json`
- Добавьте недостающие сопоставления вручную в `scripts/yandex-market-mapping.json`

### Проблема: Ошибка при обновлении через скрипт
**Решение**: 
- Проверьте, что ADMIN_TOKEN установлен правильно
- Убедитесь, что формат JSON в маппинге корректен
