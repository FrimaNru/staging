# Инструкция по извлечению товаров из Яндекс Маркета

## Способ 1: Автоматический парсинг (требует установки Puppeteer)

### Установка Puppeteer:
```bash
npm install puppeteer
```

### Запуск:
```bash
node scripts/parse-yandex-market-auto.js
```

Скрипт автоматически:
- Откроет браузер
- Загрузит страницу Яндекс Маркета
- Прокрутит страницу для загрузки всех товаров
- Извлечет все ссылки на товары
- Сохранит результат в `scripts/yandex-market-products.json`

---

## Способ 2: Ручной парсинг через браузер (рекомендуется)

### Шаг 1: Откройте страницу магазина
Перейдите по ссылке:
```
https://market.yandex.ru/business--mi-alegria/216411290?generalContext=t%3DshopInShop%3Bi%3D1%3Bbi%3D216411290%3B&rs=eJwzUnrByPiJUYaDUWDhIVYJBo179xYpaEx-dVteY9uJZkWN6y1n5AHeTw3k&searchContext=sins_ctx
```

### Шаг 2: Загрузите все товары
- Прокрутите страницу вниз до конца
- Или подождите автоматической подгрузки товаров

### Шаг 3: Откройте консоль разработчика
- Нажмите `F12` или `Ctrl+Shift+I` (Windows/Linux)
- Или `Cmd+Option+I` (Mac)
- Перейдите на вкладку "Console"

### Шаг 4: Выполните скрипт
1. Откройте файл `scripts/parse-yandex-browser-script.js`
2. Скопируйте весь код из файла
3. Вставьте в консоль браузера
4. Нажмите `Enter`

### Шаг 5: Сохраните результат
1. JSON будет скопирован в буфер обмена
2. Создайте файл `scripts/yandex-market-products.json`
3. Вставьте скопированный JSON в файл

---

## Шаг 3: Сопоставление товаров

После получения списка товаров из Яндекс Маркета, запустите скрипт сопоставления:

```bash
node scripts/match-products-with-yandex.js
```

Скрипт:
- Загрузит товары из вашей БД
- Сопоставит их с товарами из Яндекс Маркета по названиям
- Создаст маппинг в файле `scripts/yandex-market-mapping.json`
- Покажет статистику сопоставления

---

## Шаг 4: Обновление ссылок

### Вариант A: Через админ-панель
1. Откройте админ-панель → Товары
2. Нажмите "Массовое обновление Яндекс Маркет"
3. Вставьте содержимое файла `scripts/yandex-market-mapping.json`
4. Нажмите "Обновить"

### Вариант B: Через скрипт
```bash
# Windows PowerShell
$env:ADMIN_TOKEN="ваш_токен"
node scripts/add-yandex-market-urls.js

# Linux/Mac
export ADMIN_TOKEN="ваш_токен"
node scripts/add-yandex-market-urls.js
```

---

## Структура файлов

- `scripts/yandex-market-products.json` - список товаров из Яндекс Маркета
- `scripts/yandex-market-mapping.json` - маппинг товаров БД → ссылки Яндекс Маркет
- `scripts/yandex-market-unmatched.json` - товары, которые не удалось сопоставить автоматически

---

## Решение проблем

### Скрипт не находит товары
- Убедитесь, что прокрутили страницу до конца
- Подождите несколько секунд для загрузки
- Попробуйте обновить страницу и выполнить скрипт снова

### Не удается сопоставить товары
- Проверьте файл `scripts/yandex-market-unmatched.json`
- Сопоставьте товары вручную по названиям
- Добавьте их в маппинг вручную

### Ошибки при обновлении
- Проверьте, что ADMIN_TOKEN установлен правильно
- Убедитесь, что формат JSON корректен
- Проверьте, что артикулы/названия товаров совпадают
